# Medico - AI-Powered Health Assistance Platform

Medico is a web-based AI health assistance platform designed to help users understand common health concerns, ask symptom-related questions, and access quick medical guidance through an interactive AI assistant.

The platform provides a clean and responsive healthcare interface with emergency help, symptom analysis workflow, AI chat support, diagnostic data visualization, and upcoming services like doctor consultation, lab tests, and medicine ordering.

## Live Demo

https://medicoai5.netlify.app/

## Features

- AI-powered health assistant for basic medical guidance
- Symptom-based query support
- Emergency help section with 108 helpline
- Suggested health questions for quick interaction
- Diagnostic test visualization using charts
- Line chart, bar chart, and pie chart support
- Responsive and modern healthcare UI
- Smooth scrolling navigation
- Coming soon sections for:
  - Doctor consultation
  - Diagnostic tests
  - Medicine store
- Secure and user-friendly interface
- Medical disclaimer-focused guidance

## Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js
- AI Chat Backend API
- Netlify for deployment

## How It Works

1. User visits the Medico platform.
2. User can read about available health assistance services.
3. User enters a health-related question in the AI assistant.
4. The query is sent to the backend AI service.
5. The platform displays a helpful response in the chat interface.
6. Users can also visualize diagnostic data using charts.

## Main Sections

### Home

The landing section introduces Medico as an AI-powered health assistance platform for symptoms, diseases, and health concerns.

### Emergency Help

Provides quick access to emergency medical support such as the 108 helpline.

### How Medico Works

The platform follows a simple four-step flow:

1. Symptom Analysis
2. AI Medical Analysis
3. Health Report
4. Expert Support

### AI Health Assistant

The AI assistant helps users ask questions about symptoms and health concerns. It can provide general guidance and suggest when professional medical care may be needed.

### Diagnostic Test Visualization

Users can enter test values and labels to generate charts for health-related data such as blood pressure trends, sugar levels, or other diagnostic readings.

### Upcoming Services

Medico also includes planned service sections for doctor consultation, diagnostic test booking, and medicine ordering.
